================================================================
DERIVADAS (feitas à mão, sem Sympy)
================================================================
f(x)    = x * e^x
f'(x)   = e^x + x*e^x       = (x + 1) e^x   (regra do produto)
f''(x)  = e^x + (x+1)*e^x   = (x + 2) e^x
f'''(x) = e^x + (x+2)*e^x   = (x + 3) e^x
Padrão: f^(n)(x) = (x + n) * e^x

================================================================
LIMITE N DA SÉRIE (e por quê)
================================================================
N_LIMITE = 28  (vale para |x| <= 3)
Por quê:
- Com N = 28, o 1º termo descartado x^(N+1)/N! é menor que 1e-15.
- O float (double) guarda ~15 a 16 dígitos: termos menores que isso
  não mudam mais o resultado.
- Depois desse N, cada termo extra só aumenta o tempo de execução.
- Quanto maior |x|, maior o N necessário (veja a tabela).

APROXIMAÇÕES (polinômios de Taylor de x*e^x em torno de 0)
================================================================
P1(x) = x

================================================================
PROPRIEDADES
================================================================
- Série: x*e^x = soma_{k>=1} x^k / (k-1)!  (coeficientes 1/(k-1)!)
- Raio de convergência: infinito (converge para todo x real)
- Derivada n-ésima: f^(n)(x) = (x + n) * e^x   ->   f^(n)(0) = n
- f(0) = 0 ;  f'(x) = (1 + x) e^x  ->  ponto crítico em x = -1
- Mínimo global em x = -1: f(-1) = -1/e = -0.367879
- Limite: f(x) -> 0 quando x -> -infinito; f(x) -> +infinito quando x -> +infinito
- Primitiva: integral de x*e^x dx = (x - 1) e^x + C
- Erro de truncamento (grau n): R_n(x) = f^(n+1)(c) x^(n+1) / (n+1)!, c entre 0 e x
- Perto de 0 o erro é aproximadamente o 1º termo descartado: x^(n+1) / n!
